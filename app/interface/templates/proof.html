The comparison worth making

Published work on LLM‑generated architecture views finds they are “syntactically valid but semantically flawed”, commonly containing “hallucinated features or incorrect relationships that are syntactically correct but lack semantic basis” (LLM-based Automated Architecture View Generation: Where Are We Now?).

So run a generated‑diagram tool on this same repository and put the two side by side. Then try, on its output, the three things you just did here: click an arrow to the line it came from, read what it admits it missed, and generate it twice to see whether you get the same picture.

This page deliberately does not reproduce a competitor's output. A comparison that invents the other side proves nothing, and one bad-faith screenshot would cost more credibility than the whole argument is worth. Run it yourself.
