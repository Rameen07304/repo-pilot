          Agent skills

          Repositories increasingly ship configuration for AI coding agents: Claude skills, subagents, project instructions, Cursor rules, MCP servers. This finds them and tells you what each one would do if you used it yourself.

          Found by reading file paths and frontmatter, with no AI involved. These files are written to be obeyed by an agent, so everything below is shown as plain text and never acted on.

          The steps are the calls found in the code, in the order they appear. A model only ever chooses where to start.
